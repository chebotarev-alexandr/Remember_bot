# Remember Bot

Telegram-бот напоминаний с кнопочным интерфейсом, поддержкой часовых поясов, тарифами и админ-панелью.

## Возможности

- ⏰ **Однократные напоминания** — выбор даты через интерактивный календарь и времени через кнопки (часы → минуты).
- 🔁 **Регулярные напоминания** — ежедневно, еженедельно (выбор дня недели), ежемесячно (выбор числа).
- 🌍 **Часовые пояса** — каждый пользователь выбирает свой город, напоминания приходят по его локальному времени.
- 🎛 **Полностью кнопочный интерфейс** — меню, инлайн-кнопки, пагинация, без необходимости запоминать команды.
- ⭐ **Тарифы**: бесплатно — до 10 регулярных и 3 однократных напоминаний; премиум — без ограничений.
- 📋 **Управление напоминаниями** — список, пауза/возобновление, удаление.
- 🛠 **Админ-панель** — выдача/отзыв премиума, блокировка пользователей, просмотр всех напоминаний.

## Стек

- Python 3.12
- [aiogram 3](https://github.com/aiogram/aiogram) — фреймворк для Telegram-ботов (FSM, инлайн-клавиатуры)
- Django 5 + Django Admin — ORM и админ-панель
- SQLite (WAL-режим) — БД
- Docker / docker-compose — деплой

## Архитектура

```
Remember_bot/
├── bot/                      # код бота (aiogram)
│   ├── handlers/             # обработчики: старт, создание, список, таймзона, премиум
│   ├── keyboards/            # клавиатуры: меню, календарь, выбор времени, таймзоны
│   ├── dispatcher.py         # сборка Dispatcher
│   ├── middlewares.py        # регистрация + блокировка пользователей
│   ├── scheduler.py          # планировщик напоминаний (is_due + цикл)
│   ├── limits.py             # лимиты бесплатного тарифа
│   └── states.py             # FSM-состояния
├── config/                   # Django-проект
├── core/                     # приложение: модели, админка, команда runbot, сигналы WAL
├── Dockerfile
├── docker-compose.yml
└── manage.py
```

Три сервиса в docker-compose:

- **bot** — long-polling бота + фоновый планировщик (`manage.py runbot`).
- **web** — Django-админка через gunicorn (порт 8000 → хост 8091).
- **migrate** — одноразовая миграция при старте.

Бот и админка разделяют одну SQLite-БД через volume `./data`.

## Быстрый старт (Docker)

```bash
# 1. Скопируйте .env и впишите токен бота
cp .env.example .env
# BOT_TOKEN=123456789:AA...  (токен от @BotFather)

# 2. Соберите и поднимите
docker compose up -d --build

# 3. Создайте суперпользователя для админки
docker compose run --rm -e DJANGO_SUPERUSER_USERNAME=admin \
  -e DJANGO_SUPERUSER_PASSWORD=пароль -e DJANGO_SUPERUSER_EMAIL=admin@example.com \
  web python manage.py createsuperuser --noinput
```

Админка: `http://<хост>:8091/admin/`

## Локальная разработка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env   # впишите BOT_TOKEN
python manage.py migrate
python manage.py runbot        # запуск бота
python manage.py runserver     # админка (http://127.0.0.1:8000/admin/)
```

## Переменные окружения (`.env`)

| Переменная | Описание | По умолчанию |
| --- | --- | --- |
| `BOT_TOKEN` | Токен бота от @BotFather | — |
| `DJANGO_SECRET_KEY` | Секретный ключ Django | dev-ключ |
| `DJANGO_DEBUG` | Режим отладки (`1`/`0`) | `1` |
| `DJANGO_ALLOWED_HOSTS` | Разрешённые хосты (через запятую) | `*` |
| `DATABASE_PATH` | Путь к SQLite-БД (для Docker — `/app/data/db.sqlite3`) | `db.sqlite3` |
| `FREE_REGULAR_LIMIT` | Лимит регулярных напоминаний (бесплатный тариф) | `10` |
| `FREE_ONCE_LIMIT` | Лимит однократных напоминаний (бесплатный тариф) | `3` |

## Админ-панель

В разделе **Пользователи** (`TelegramUser`) можно:

- ⭐ выдать / отозвать **премиум** (действие из выпадающего списка или чекбокс в списке);
- 🔒 **заблокировать** / разблокировать пользователя (заблокированный не может пользоваться ботом);
- править часовой пояс, смотреть дату регистрации.

В разделе **Напоминания** (`Reminder`) — все напоминания с фильтрами по типу и активности.

## Лимиты бесплатного тарифа

| Тип | Бесплатно | Премиум |
| --- | --- | --- |
| Регулярные (ежедневно/еженедельно/ежемесячно) | 10 | ∞ |
| Однократные | 3 | ∞ |

При превышении лимита бот сообщает об этом и предлагает премиум.
